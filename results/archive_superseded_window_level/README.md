# Superseded: window-level (leaky) fine-tuning results

These files come from the first fine-tuning experiments. Labeled WISDM windows were drawn from all WISDM windows and the model was tested on all WISDM windows, so test subjects also appeared in the adaptation data. Windows from one subject overlap and share patterns, so accuracy was inflated (fine-tune 96-98%, meta-only 76.88%).

Do NOT cite any number in this folder. The thesis uses only the subject-wise results in `results/phase3/D_subject_wise/` (20 held-out WISDM subjects, 10 seeds, adaptation windows from the other 31 subjects).

Contents:
- `phase3/B_meta_learner_adaptation/`, `phase3/C_finetune_learning_curve/`, `phase3/priority4/`: old window-level outputs (generated by `phase3_domain_adaptation.py` experiments B and C, and `learning_curve.py`).
- `tables/master_table.csv`: old consolidated table (built by `build_master_table.py`), contains the leaky fine-tune and meta-only rows.
- `extend_base_learner_diagnostics/`: the old diagnostic table with leaky WISDM FineTune columns, and the old bar chart that shows them. The live table in `results/phase3/extend_base_learner_diagnostics/` has those two columns removed.
